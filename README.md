## Структура проекта

В репозитории есть две ветки. Последняя рабочая версия сохранена в ветке `last-version` — в её последнем коммите находится актуальный код проекта.

### Основные файлы

В папке `vibefinance` находятся ключевые рабочие файлы:

- **`app.py`** — запускает весь проект. При запуске создаётся локальный сервер, на котором работает сайт.
- **`main.html`** — фронтенд-часть приложения.
- **`classificator.py`** — парсит входящий текст от пользователя и преобразует его в JSON.
- **`psyhicologict_agent.py`** — отвечает за эмоциональную реакцию на траты, а также даёт ответы на общие вопросы о финансах.
- **`workflow.py`** — объединяет агентов с помощью **LangGraph**.
- **`.env`** — файл с переменными окружения.
