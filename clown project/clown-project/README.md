# Clown Project

Проект для работы с финансовыми данными и классификацией.

## Структура проекта

- `VibeFinance/` - основная папка с приложением
  - `app.py` - главный файл приложения
  - `classificator.py` - модуль классификации
  - `main.html` - HTML интерфейс

## Установка и запуск

1. Установите необходимые зависимости:
   ```bash
   pip install flask langchain-gigachat langchain-core python-dotenv
   ```

2. Создайте файл `.env` с вашими учетными данными GigaChat:
   ```
   GIGACHAT_CREDENTIALS=ваши_учетные_данные
   ```

3. Запустите приложение:
   ```bash
   python VibeFinance/app.py
   ```

4. Откройте браузер по адресу: `http://localhost:5000`

## Функциональность

- ✅ Регистрация и вход пользователей
- ✅ Сохранение трат с автоматической классификацией
- ✅ Просмотр сохраненных трат (команды: "показать траты", "мои траты", "история трат")
- ✅ Красивый веб-интерфейс
- ✅ Работа с базой данных SQLite
